# Grid and Layout

## Desktop grid

- 12 columns
- max content width: `1440px`
- page padding: `48–64px`
- column gap: `24px`

Do not automatically center every composition.
Intentional asymmetry is encouraged.

## Tablet

- 8 columns
- page padding: `32px`
- gap: `20–24px`

## Mobile

- 4 columns
- page padding: `20px`
- gap: `16px`

## Alignment

Text, images, dividers, labels, and shapes should align to the grid.

Avoid arbitrary floating elements.

A composition may intentionally break the grid, but the break should be visually obvious and purposeful.

## Homepage structure

Recommended order:

1. `00 — Hero`
2. `01 — Selected Work`
3. `02 — About`
4. `03 — Experience`
5. `04 — Contact`

The homepage can be more visually expressive than individual case-study pages.

## Hero

The hero should establish identity quickly.

Prioritize:

- name
- product-design positioning
- one concise positioning statement
- strong typography
- restrained geometric accent
- clear route into selected work

Do not overload the hero with biography, skill lists, or multiple calls to action.

## Selected work

Projects should feel editorial rather than like a generic card grid.

Use:

- project number
- project title
- short descriptor
- discipline / scope metadata
- one dominant image
- project accent

Avoid excessive rounded cards.

## About and experience

Keep these sections concise on the homepage.
Detailed history can live on a dedicated About page if needed.

## Section rhythm

Alternate dense and open compositions.
Not every section should use the same template.

Use visual rhythm through:

- whitespace
- scale changes
- image size changes
- text/image alignment
- rules
- numbering
